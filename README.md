---

## ✨ Recursos e Destaques Implementados

- **Tema Dark com Identidade Visual Roxa:** Estilização customizada em CSS externo (`style.css`) utilizando variáveis CSS (`:root`) e sobrescrita de componentes do Bootstrap 5.3.
- **Carousel com Efeito *Ken Burns* e Legendas:** Transição suave entre slides com animação contínua de zoom (`@keyframes`), degradê para contraste de leitura e chamadas para ação.
- **Seção de Formação & Trajetória (Timeline):** Linha do tempo vertical construída com CSS puro (`::before` e posicionamento relativo/absoluto) conectando minha formação técnica em Desenvolvimento de Sistemas com minha experiência atual em design gráfico (álbuns de figurinhas esportivos) e designer têxtil.
- **Microinterações e Animações (`hover`):**
  - Sublinhado animado nos links da barra de navegação.
  - Elevação suave e brilho roxo nas bordas dos cards.
  - Zoom interno controlado (`overflow: hidden`) nas imagens dos projetos.
  - Animação de escala e rotação nos ícones das tecnologias.
- **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops utilizando o sistema de grid do Bootstrap.
